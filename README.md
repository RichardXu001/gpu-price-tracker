# GPU Rental Price Tracker

Independent static reference for cloud GPU rental pricing: tracked hourly ranges, medians,
reserved and spot rates for RTX 4090, H100 and A100, plus provider averages. Every figure
carries a named source (Coloprice, GPUFinder, gputracker.dev, Akash/GetDeploying) and a
capture date. No trackers are mixed within a single table.

Content sources: public price trackers and provider-published rates as quoted by them.
All trademarks belong to their owners. Not affiliated with any provider.

Deployed at: https://richardxu001.github.io/gpu-price-tracker/ (GitHub Pages, deploy from main).
